# AgroFuturo 2026: Inteligência Artificial e Sustentabilidade

## 🌾 Tema da Página Criada
A aplicação apresenta o ecossistema conceitual e prático do **Agro forte, futuro sustentável: equilíbrio entre produção e meio ambiente**. O foco central da interface reside em reposicionar a percepção mercadológica global do Brasil de mero exportador de commodities para líder em biotecnologia tropical e aplicação de Inteligência Artificial preditiva no campo.

## 🎯 Objetivo da Página
* **Disseminar Conhecimento**: Apresentar os avanços tecnológicos desenvolvidos no país (como as bactérias fixadoras de nitrogênio) e as soluções trazidas pela IA (automação, rastreabilidade, economia hídrica).
* **Engajamento Hub**: Prover um funil funcional de captação para seminários educacionais online por meio de formulários inteligentes.
* **Acessibilidade Universal**: Servir como modelo de aplicação inclusiva que utiliza recursos nativos do ecossistema Web moderno para garantir o acesso a múltiplos perfis de usuários.

## ⚙️ Instruções de Uso da Página Criada
1.  **Instalação**: Salve os três arquivos (`index.html`, `style.css` e `script.js`) no mesmo diretório/pasta raiz do seu computador.
2.  **Imagens Reservadas**: A estrutura do código prevê cinco imagens (`Foto1.png` a `Foto5.png`). Insira imagens de sua escolha com esses nomes exatos na mesma pasta para vê-las renderizadas com os efeitos de animação e sombreamento premium.
3.  **Visualização**: Abra o arquivo `index.html` em qualquer navegador web moderno atualizado (Chrome, Edge, Firefox ou Safari).
4.  **Menu de Acessibilidade Flutuante**:
    * Clique em **A+** ou **A-** para escalonar todas as fontes da aplicação proporcionalmente.
    * Utilize o botão de alternância **🌓** para mudar o ecossistema visual de Dark-Tech (padrão) para o modo Light-Sustentável.
    * Pressione **🔊 Ler** para escutar o artigo principal de forma automatizada pelo navegador. Use o **⏹️ Parar** para interrompê-la a qualquer momento.
